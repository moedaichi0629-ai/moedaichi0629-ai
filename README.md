# もえ｜AI・業務自動化

Googleサービス・LINE・AIを組み合わせ、日々の手作業を減らすツールを制作しています。

使う人が迷わず操作できる画面と、結果を確認・修正しやすい運用を大切にしています。

[AIポートフォリオ](moedaichi0629-ai.github.io) · [デザイン作品](https://fori.io/rilymoe0902)

## 制作しているもの

- **Google業務自動化**：スプレッドシートへの記録・集計、フォーム・カレンダー・Gmailの連携
- **LINE Bot**：FAQ回答、スタッフへの引き継ぎ、記録・通知
- **AI活用ツール**：文章・記事の下書き生成、画像解析、案件分析
- **Webアプリ**：情報収集・管理画面・業務データの可視化

## 制作で意識していること

- AIの生成結果を人が確認できる導線を設ける
- エラー時の状態を記録し、再実行やスタッフ確認につなげる
- 実装済みの機能と今後の予定を区別して説明する
- APIキーなどの秘密情報をコードから分離する
